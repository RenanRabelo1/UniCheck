# UniCheck

Sistema web para o controle de empréstimos de materiais e chaves da Secretaria do CCT da Unifor.

## Estrutura inicial

- `client/`: aplicação React.
- `server/`: API REST em Node.js.
- `docs/`: requisitos, diagramas e protótipos do projeto.

No back-end, cada módulo deverá concentrar suas rotas, controller, service, repository e validações. A API aplicará as regras de permissões, disponibilidade, aprovação por item, retirada, devolução e alertas de atraso.
